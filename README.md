# BS2C-Algorithm
This repository contains the code for the paper:
**"BS2C: Boosting Semi-Supervised Regressor via Confidence-Weighted Consistency Regularization"**

## Introduction
**BS2C**  is an extension and further work of **BSRU**.
The original BSRU code can be found:
[https://github.com/zuohaimin/BSRU-Algorithm](https://github.com/zuohaimin/BSRU-Algorithm)
